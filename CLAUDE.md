Before delegating implementation work to an Antigravity subagent, read
[docs/SUBAGENTS.md](docs/SUBAGENTS.md). Delegation runs through the Antigravity UI: you
write a brief to a file and hand the human a short prompt to paste, because copy/paste
mangles formatting. The doc also records which work is safe to delegate and which must be
verified at source.
